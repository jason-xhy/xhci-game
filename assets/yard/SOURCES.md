# Yard materials

These CC0 materials are stored locally as WebP.

- [Asphalt 01](https://polyhaven.com/a/asphalt_01) by Charlotte Baglioni (photography) and Dario Barresi (processing).
- [Blue Metal Plate](https://polyhaven.com/a/blue_metal_plate) from Poly Haven.

The color maps use the sRGB color space. OpenGL normal and roughness maps are linear data. The assets were converted from the publisher's 1K JPEGs.
