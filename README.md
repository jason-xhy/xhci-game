Cycle ownership exercise: I selects the next TRB entry; O selects Command,
EP0 or Event Ring; F publishes the expected Cycle bit at the selected stalled
head and rings the endpoint doorbell again. GET_DESCRIPTOR deliberately has
an incorrect first Cycle bit. Inspect it and press F to resume. xHC stops at the first mismatched entry; earlier entries remain consumed. No completion
is produced until the entire submission is consumed. The ring ledger displays ENQ/DEQ
indices and producer/consumer cycle states. Each ring has four displayed entries and reserves one slot (capacity three);
wrap toggles its cycle state. Retired entries retain their fields for inspection.

This is a compact single-segment teaching abstraction: command/transfer wrap
stands in for a Link TRB with Toggle Cycle, without allocating a visible Link
entry. Event Ring wrap follows segment-table traversal and never uses Link
TRBs. Event software consumption advances ERDP; it does not ring a doorbell.
Addresses shown in the inspector are illustrative offsets, not DMA addresses.
