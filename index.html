FIRST SHIFT
让一台 USB2 设备从接入走到可用。跟随 Command、Transfer 和 Event 三条环完成第一次枚举。
默认配置自动执行启动序列。手动启动可检查 DMA 地址和寄存器。
ENGINEER'S FIELD MANUAL
Three lines. Two producers.
Command Ring · amber: software produces command TRBs; xHC consumes them after doorbell 0.
Transfer Ring · cyan: software produces transfer TRBs for an endpoint; xHC consumes them after the slot/endpoint doorbell. This factory shows EP0, not one universal transfer ring.
Event Ring · green: xHC produces events; the host driver handles the IRQ, reads matching events and advances ERDP. It is not another command submission line.
E queues a submission; B writes its doorbell; H steps through the driver handler after IRQ delivery. O selects a ring; I selects one of its four retained slots. ENQ marks the next producer slot and DEQ the next consumer slot. A matching Cycle grants ownership. GET_DESCRIPTOR deliberately stalls: select the Transfer Ring dequeue entry, compare C with CCS, then press F to publish the expected Cycle and ring again. xHC consumes entries in order and stops at the first Cycle mismatch. One slot remains reserved to distinguish full from empty. Command/transfer wrap models an implicit Link toggle; Event Ring wraps by segment traversal.
Mission: USB2 root port attach → reset → Enable Slot → contexts → Address Device (BSR=0) → descriptors → Configure Endpoint → SET_CONFIGURATION.
Source: xHCI Rev 1.2b §4.3, printed pp. 71–80. This mission covers the primary path through §4.3.5. Use Chapter 4 laboratories for alternate-interface changes, speed/TT contexts, bandwidth recovery and later topics. The laboratories are partially integrated teaching models; the primary factory mission remains §4.3.1–5.
Linux navigation: drivers/usb/host/xhci{,-hub,-mem,-ring}.c. Symbol hints are illustrative and can vary by kernel. USB3 usually enables automatically on attachment; this mission deliberately uses USB2 and software reset.
