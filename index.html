ENGINEER'S FIELD MANUAL
Three lines. Two producers.
Command Ring · amber: software produces command TRBs; xHC consumes them after doorbell 0.
Transfer Ring · cyan: software produces transfer TRBs for an endpoint; xHC consumes them after the slot/endpoint doorbell. This factory shows EP0, not one universal transfer ring.
Event Ring · green: xHC produces events; software consumes them and advances ERDP. It is not another command submission line.
O selects a ring; I selects one of its four retained slots. ENQ marks the next producer slot and DEQ the next consumer slot. A matching Cycle grants ownership. GET_DESCRIPTOR deliberately stalls: its head is selected automatically; press F to publish the expected Cycle and ring again. xHC consumes entries in order and stops at the first Cycle mismatch. One slot remains reserved to distinguish full from empty. Command/transfer wrap models an implicit Link toggle; Event Ring wraps by segment traversal.
Mission: USB2 root port attach → reset → Enable Slot → contexts → Address Device (BSR=0) → descriptors → Configure Endpoint → SET_CONFIGURATION.
